# MES-016 點擊同步修正

使用者回報：直接點 ER 時右圖停在概覽。精確點節點的本機基準可更新，未能完全重現使用者當時狀態；確認總覽的小節點易點偏，以及三種物件共用一張图但沒有圖上焦點。

已修改：點擊可選近距離節點，真正拖曳後才移圖；單一 pointerup 處理選取。右側顯示目前物件、其物理意義，Lot/FOUP/EQP 有不同圖面框選，Flow/Recipe 切换對應圖。大圖同步保留框選。維持初始完整 ER。

驗證以真實 mouse.click / touchscreen.tap，並非只呼叫 JS API：1440/390 五種節點、桌面近距離命中、拖曳不誤選、放大圖標記。另回歸 MES-015。新截圖及結果見 tests/evidence/mes-016。手機節點密集，鄰近另一節點時尊重直接命中的節點，不強行吸附 Lot。

未增加右側切換按鈕；本次依使用者澄清，修正 ER 本身連動。原 SVG 及教學圖資產未修改。沒有宣稱新的視覺評分或使用者驗收。
