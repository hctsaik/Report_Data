## 共識表態：附條件同意 C 主體，結合 A 排版與 B 局部閱讀

1. 預設 Lot 圖使用 C 的 8 節點／8 原邊：Lot、FOUP、EQP、Flow，加放在、預到、Flow 定義、FOUP 位於 EQP 四菱形。Lot 是視覺主詞，不把「預到」改寫成「目前加工設備」。
2. A 的主詞中心與分組布局僅是布局，不把 A 的 28 節點全閉包塞進初始圖；不然失去此次改版的意義。
3. B 的橫向逐關係閱讀用於選定分支，屬同一份資料的閱讀視圖，不能重新省略三端關係，不能把線變箭頭暗示流程順序。
4. 普通點 EQP 或其他節點，只更新選取與右側教學；唯有明確點「改以 EQP 為主詞」才換主題，避免前次右圖不同步問題被偷換成跳頁。
5. 所有同義疑慮以來源原關係為準；特別是同一 EQP 節點僅表示表／實體類型，Lot 預到 EQP 與 FOUP 位於 EQP **不保證是同一筆設備實例**。教學可舉兩者設備 ID 相同／不同，不能畫成必定同台。
6. C 的 EQP 主題提到 Recipe、OEE 延伸，但模型中的裸 FREQP、KER 設備等沒有已證實同表橋接，不能靠「也是設備」連回 SIVIEW.FREQP。獨立延伸片段需明示來源身分未確認。
7. 每張主題初始圖須有固定可分享狀態，列出可展開分支及完整大圖入口；未展開不叫「遺失」，但要能追溯。

沒有反對 C 方向；上述 5、6 是不可放寬的語意限制。原型製作後仍需實看才能確認 8 節點布局與並排插圖真的容易理解。
