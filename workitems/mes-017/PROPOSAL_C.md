# 提案 C：主詞概覽＋分支逐層展開

本提案是設計審查，未改網站、未產生成品評分。依據 `ER/INTEGRATED/er-model-v2.json` 與 MES-014 ER 量表；以下路徑已核對模型中的實際節點與邊。

## 基本畫法

每個主詞有獨立 ER 視圖與可分享網址：Lot、EQP、FOUP、Flow。圖面主詞放中央偏左，使用原有類別色與較粗框線，標題明確寫「以 Lot 看裝載、設備安排與流程」。其他物件保留原類別顏色、實體矩形、關係菱形及鍵，不把它們降為圖示或摘要卡。主詞不是獨占類型的篩選器：Lot 圖必須同時看到 FOUP、EQP、Flow。

預設只顯示教材精選的完整支線；「展開裝載／管制／歷史」逐段加入完整關係。展開鈕位於圖框外，不畫成假的 ER 節點。圖上標示「主題視圖；其他關係可展開」，避免讀者把目前所見當成全模型。

## Lot 的預設圖：8 個節點，8 條真實線

四個資料實體是 Lot、FOUP、EQP、Flow；四個關係節點如下。這是小型 ER 而非四張物件卡。

- `LOT / Siview.Frlot` —「放在 / Siview.Frcast_lot」— `FOUP / Siview.Frcast`。
- `LOT` —「預到 / Siview.Frlot_EQP」— `EQP / Siview.freqp`。
- `LOT` —「Flow 定義 / Part / Mainpd_id」— `Flow / F12DM.DM_Flow_step_Bt`。
- 同圖保留 `FOUP` —「位於 / eqp_id / Siview.CSFHDOPHS」— `EQP`，避免裝載與设备位置的物理意義斷開。

主詞 Lot 放左中、FOUP 在右上、EQP 在右中、Flow 在右下。關係菱形在對應端點之間；FOUP 到 EQP 的位置支線沿右側連接，不穿越 Lot 至 EQP 的預到菱形。預到和位於是兩種不同證據，不能因為同指設備而收成一条線。沒有根據的箭頭、基數一律不加。

點「裝載細節」可加入 Slot 支線；點「設備交接」可加入 Port 完整支線；点「管制」可加入 Future Hold。這些不是自動 BFS 的全部一跳鄰居，而是維護於主題 manifest 的實際路徑集合。任何支線顯示時不能略去中介關係或只露出一個孤立終點。

## 其他主詞的預設重心

- FOUP：Lot 裝載＋Slot、FOUP 位於 EQP、FOUP 預派 EQP。凸顯載具是位置／搬送的主體，搬送歷史作為下一段。
- EQP：FOUP 位置、Lot 預到、EQP 與 Port／Chamber。預設保留所選關係全部中介節點；Recipe、OEE 分段展開。不同 schema 的同名 EQP 不強併，必要時做另一張明示身分未確認的局部圖。
- Flow：Lot 經 Part／Mainpd_id 接到 Flow，Flow 經 LCRECIPE_ID 接到 LR／設備對應。不能為了讓所有主題都有 EQP 方框而新增原模型不存在的 Flow→EQP 捷徑；設備端的其他配置圖可以明示另段查看。

## 防止再長回巨圖

每次只展開一個教學分支；主幹仍在、其他展開分支收回。畫布範圍維持可读實體名稱，不用全圖縮小來容納新內容。若某一完整關係仍超出 1440 寬桌面的可讀範圍，另開該主題的詳圖，回到主題圖時恢復原位置。

不能把「最多 12 節點」當硬規則切斷關係。以桌面及投影的文字可讀性、無交叉誤讀、關係完整為驗收條件；手機以局部圖與完整支線分頁閱讀，不承諾一屏字全可讀。

## 跨主題的一致性與完整性

所有主題引用同一 canonical node ID、edge ID，標籤與色彩從模型讀取。相同實體可在多張主題圖出現，切換主詞不是資料複製或重新合併。點 FOUP 的「以此為主詞」會切到 FOUP 圖並保留該物件高亮；完整 ER 保留作為總索引。

建立 coverage manifest：全模型每個節點與每條線在哪張主題／詳圖可見；尚未分配者必須明示在完整圖可到達，不能宣稱主題預設圖已無遺漏。完整性有兩層：預設主題支線不得中斷，全資料模型仍全部保留且可追溯。

## 主要風險與必要修正

1. 展開使空間位置跳動，聽眾迷路：固定主幹位置，分支在預留區域加入；保持主詞位置與選取狀態。
2. 收起後誤以為沒有其他關係：圖外列分支清單與「尚有 N 段」，完整圖入口固定可見。
3. 展開過多再變大圖：單一分支模式，詳圖另開；不能無限累加。
4. 可操作但不適合課堂截圖：各主題提供固定預設構圖與可分享的選定分支 URL。
5. 同一 FOUP/EQP 在不同主題位置改變：固定顏色、完整表名和身分，切換時明示主詞更換；不以座標代表語意。
