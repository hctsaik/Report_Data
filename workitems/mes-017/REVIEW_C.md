## 建議共識及態度

**附條件同意 C 的兩層策略，採 B 的左到右固定構圖，採 A 的完整關係閉包規則。**

1. 第一層是各主詞固定核心 ER，不是點一下巨圖換高亮；Lot 核心先採 C 的8節點8邊作原型候選。
2. 第二層是可單獨閱讀的完整分支詳圖，核心保留可回去的定位，無限累加展開不採用。
3. 每個被選菱形含所有端點、鍵與原邊；Move 三端關係是必測案例。
4. 四主題共享 canonical ID／顏色／標籤；未確認 schema 節點不接假線。
5. 頁面明示這是精選主題範圍，完整ER與來源圖可回查。Coverage manifest 是製作前必要項，不以全圖還在掩蓋詳圖遺漏。
6. 右側對應圖與節點點擊必須實測；新主題不是恢復成只更新標題、不換圖面焦點。
