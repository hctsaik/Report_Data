# MES-035 Load Port現場圖

使用者要求機台/OHT/Wafer/Load Port同圖，Port為等待加工或加工完成後暫置位置。
說明載有晶圓的FOUP停在Load Port，不畫裸晶圓直接放平台或OHT直接抓Wafer。
三時點同一FOUP的C故事：OHT送達→Port暫置/等待加工→加工後返回Port等待OHT搬離；同一機台/LP1/F012/W07，時點分開。中間局部剖面顯示FOUP內Wafer，機台腔體只背景輔助，不假設整FOUP進機台。
桌面16:9和手機直向。白底、藍框、具體OHT懸吊/Load Port，黃色結語「Load Port 是載具交接與暫置的位置；晶圓放在 FOUP 裡」。示例非實際廠區。檢查兩等待狀態及四必要角色可辨。
