Tool：接手晶圓工作的設備。

Equipment 或 Tool 都可以指設備。不同設備負責不同工作，例如蝕刻、清洗或量測；設備也有自己的編號。

沿用第一課的 ETCH-03

這是整台設備的名字。

ETCH-03 是本課假設的一台蝕刻設備。蝕刻可以先理解成「依圖形需求移除部分材料」，這裡先認識它的角色。

哪台設備接手？tool_id = ETCH-03

ETCH 是教學用的可讀編號；現場設備命名由工廠決定。

同一個 Lot 會依流程經過不同設備。

W07 被送到新設備時，Wafer 身分仍是 W07；改變的是它的工作位置與正在執行的步驟。

☀

Tool 回答「由哪台設備做這項工作」。

Load Port：FOUP 與設備的交接位置。

FOUP 到設備前方停靠的位置，常稱 Load Port。本課沿用 LP1，表示 ETCH-03 的其中一個交接位置。

要說清載具停在哪裡，需要一起說設備與 Port。別台設備也可以有一個叫 LP1 的位置。

「已到達 Port」就代表已開始加工嗎？

還不能直接這樣判斷。載具停靠、確認晶圓與配方、開始加工，是不同事件。設備還會有實際的載具交接與檢查流程；本課情境 A 先練習分清搬送與加工。

☀

Load Port 是載具交接的位置；Slot 是載具內晶圓的位置。

Chamber：設備裡執行製程的空間。

有些設備會把晶圓送進 Chamber（製程腔體）加工。一台設備可能有多個腔體，分別需要追蹤；設備結構不一定都相同。

Route 看順序，Recipe 看做法。

Route 是安排好的製程路線；Step 是路線上的一步。Recipe（配方）則指定某一步在設備上如何執行。

Step 名稱相同，不代表所有設備都用同一份配方。

配方要依產品、步驟、設備與版本等條件匹配。本課用配方 ID 與版本做簡化核對，不提供實際製程參數。

Track-in / Track-out 又是什麼？

通常用來記錄一批或一次作業進入／離開某站點的事件。實際定義由工廠決定；不要把它們一律當成 FOUP 實體到達／離開 Port，或 Chamber 的開始／結束訊號。

☀

Route／Step 指出目前要做哪一步；Recipe 指出這一步的加工設定。

設備之間，誰在搬 FOUP？

AMHS 是自動化物料搬運系統。常見的組成包括在上方軌道行走、升降載具的 OHT，以及暫存載具的 Stocker。

Slot 是盒內位置；Stocker 是存放盒子的設備。

整個 FOUP 搬動時，裡面的晶圓可以仍在原本的 Slot；改變的是 FOUP 在廠內的位置。

目的地已指定、正在搬送、已到達，要用不同狀態記錄。

在哪裡，和能不能加工，是兩件事。

晶圓的位置說明「去哪裡找它」。狀態說明「現在進行到哪裡、是否允許下一步」，而且要先說清楚在描述誰。

    情境 C：設備有空，為什麼不能開工？

    L023 被標為 Hold，原因是「上一站量測結果待複核」。F012 仍在 LP1，設備也空閒。先試著開工，再看看缺少了什麼。
