# MES-011｜把已確認 ER 圖接進教學網站

使用者授權：將七張 ER SVG 放進網站，連結物理與資料意義。保留 ER/NEW 已校字成品，不更改其資料定義或自行補 Join。先完成一頁原型，再擴展其餘六張的導讀。新增 data-map.html/css/js，既有首頁及各課加入入口，原圖檢視器加入返回教學。

閱讀主線：現場問題 → 物件／作業責任 → 圖中表與欄位 → 可支持及不可支持的判斷。原型以2671／2676的Lot與FOUP為例，參考既有 index.html#fab 的實物與資料分離方式。七張圖是使用者指定的完整 ER 參考，不重畫成三節點插畫，也不以全圖縮小後字小當作手機教學主線；手機預設先讀文字導讀、資料對照與案例，完整圖可縮放。

新教學：七張圖各有兩個可切換工作問題，點選後更新對照資料、選型理由、自測與 SVG 聚焦。保留圖中缺少的基數、Join 組合鍵、有效時間、來源 freshness、ER 到實際執行 Recipe 的未證部分。圖上系統名稱不自動等於 Source of Truth，表名不等於即時保證。

沿用量表v1權重：必要原理評MES角色與關係；比較評同一工作問題的資料責任取捨；原ER圖為來源附件，非本輪新製機制插畫。新頁面的主線與互動另評。驗證七個hash、兩種案例、SVG焦點／完整圖／縮放、手機與桌面、跨課入口、原SVG hash不變。截圖實看並記錄缺陷修正。使用者驗收獨立於自評。

本輪學習：ER連線只支持「原圖列出了這個關係」，不能獨自證明可執行SQL或現場加工資格。教學要把現場事實、資料記錄、查詢條件、使用結論分層，並展示同一Lot的不同答案為何不矛盾。
