# MES-010：使用者確認的廠內定義與講解稿

本輪來源：使用者六點補充。此文件區分已確認的廠內定義、通用用途與示例。AAA 正式名稱、AVL／Eff／Lost／Up 的定義尚未確認；本輪不建立其狀態或計算式。

## CW — Control Wafer

廠內已確認：Monitor Wafer、Dummy Wafer、Seasoning Wafer 都算在 CW。以下依主要用途介紹，不把三種名稱畫成所有廠都互斥的晶圓材質，也不以外觀區分。

- Monitor Wafer：用於得到可判讀的監控結果，例如膜厚、粒子或蝕刻結果。重點是「量到什麼，是否符合要求」。它是晶圓用途；MON 是作業類型。
- Dummy Wafer：用於非產品用途，例如在適用的批次製程補足裝載位置或提供所需的負載条件。是否能補位、使用哪種規格由設備與製程規定，不是任意空片都可以用。
- Seasoning Wafer：用於設備／腔體調整，使加工環境建立或恢復到需要的條件。常見於清潔、保養後依規定執行的調整作業；跑完不等於已證明監控合格。

三者都是本廠 CW 管理範圍；主要任務分別是監測結果、提供負載／補位、調整製程環境。Dummy 也可能被用於 seasoning，因此要看這次用途與規範，不能只由名稱推断壽命、可重用次數或互換性。

通用用途參考：[seasoning 使用 dummy wafer 並另行檢查結果的技術例](https://patents.google.com/patent/WO2003077303A1/en)。本廠 CW 分類由使用者確認，優先於外部廠商分類。

Dummy 補位用途另核對：[Heraeus 製造商的 filler／dummy wafer 批次爐製程用途](https://www.heraeus-covantics.com/brands/black-quartz-hbq/heraeus-black-quartz-wafer)。只引用用途，不將其材質、壽命或效能主張套用到本廠。

## Sub Route

廠內已確認：Lot 暫時切換去走另一條 Route，例如加量；哪裡出去，就回哪裡。不是永久更换主 Route。

使用者另確認：加量指追加量測。教學示例：L023 原本在 F-DEMO v1 的 S50，記下返回位置後進入 SR-ADD v1 做追加量測，完成後回到 F-DEMO v1 / S50，然後依原站規則繼續。SR-ADD 名稱為假設，不捏造追加量測的具體項目或參數。

查詢要分清主 Route、目前正在執行的 Route、子流程位置與返回 Route／Step。回到 S50 不等於 S50 自動完成，也不等於直接跳到 S60。進出子流程本身是否產生可計 Move 的事件，不能只由路徑切換推算。

## Move

廠內已確認：Move 指過站事件，單位是 Lot，重工計入。它不等於搬運次數，也不等於 Wafer 數或不同 Lot 的去重數。

例：L023 的 S40 正常過站一次、S40 重工過站一次、S50 過站一次，合計 3 個 Lot Move，涉及的不同 Lot 仍只有 1 批。若來源重送相同事件，查詢須辨識事件唯一性，不能把同一事件重複計算。具體哪些交易屬於已成立的過站事件、撤銷如何處理，仍依廠內記錄定義；本課只把標示「過站成立」的示例納入。

## MON、PM、Daily MON 與 EMS

廠內已確認：MON 是作業類型，用於監控設備或製程表現，例如確認膜厚、粒子、蝕刻結果是否符合要求。Monitor Wafer 是材料角色，MON 是工作角色。

PM 是 Preventive Maintenance，預防性保養。PM 保養工作完成不等於可以無條件加工；還要看適用的驗證與監控條件。是否每次 PM 都需要特定 seasoning 或 MON，仍須依設備規範，不能一概自動串接。

Daily MON 是例行監控作業。使用者確認：逾期不能加工，會卡 EMS（EQM Monitor System）。畫面必須呈現「Daily MON 逾期 → EMS 阻擋生產加工」。此限制不能推論為連補做 MON 都禁止。

未確認：週期是每日／每班／固定時數、何時開始計時、合格後如何由 EMS 更新與解除。因此示例用有效／逾期標籤，不捏造 24 小時週期或一按即自動解鎖。補做完成後，仍需結果被接受且 EMS 條件更新；即使 EMS 此項通過，其他 Hold／配方／設備條件仍要核對。
