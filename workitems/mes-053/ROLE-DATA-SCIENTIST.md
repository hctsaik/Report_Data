# 資深 Data Scientist 視角：從業務問題走到可驗證的資料答案

本報告為 AI 模擬角色的獨立審查，不是真人訪談。2026-09-13。方法為閱讀網站 HTML／JavaScript、ER 閱讀邏輯與廠內定義紀錄；本角色未操作瀏覽器、不宣稱完成視覺或使用者測試。沒有修改網站。

## 判斷

網站已累積足夠多的物理意義與廠內語意，主要缺口是尚未把它們組成一條「問題 → 對象 → 時間 → 資料 → 關聯驗證 → 結論限制」的學習路徑。現在讀者可以認識很多表，仍可能不會判斷一次 Join 是否把數量放大、報表回答的是哪個時刻，或模型是否用了當時還不知道的資料。

不建議以重新畫完整 ER 或增加更多主題圖片作為本次重構的第一步。保留真正 ER、來源可追溯性與既有圖片，先建立課程順序、每課資料契約與串聯案例。ER 應兼具查詢工具與進階課練習，不必成為所有讀者的第一個畫面。

## 建議的全站架構

以三個互通入口承載同一套內容，避免複製三份教材：

1. **循序課程**：先修關係、能力目標、前後課、練習與完成證據。
2. **工作問題**：找貨、查加工、追歷史、解釋報表等入口；每題指出需查哪些對象與時間。
3. **資料參考**：保留完整 ER、表名與同義詞搜尋、來源對照、廠內定義；可跳到相關課程與練習。

三個入口不能是三種真相。每個主題共用唯一定義、已確認／示例／待確認標示、相關表引用與版本。學習頁提供逐步解說；參考頁提供精確檢索；練習頁提供待作答的任務。

建議資料能力順序：

|階段|要能回答|現有內容可用|新增的橋接|
|---|---|---|---|

報表層課題應放在對象、時間、事件之後。WPH 預估到站屬於「定義＋假設→預測」，KER 指標屬於「時間範圍＋群組範圍→報表」，兩者不要因都提到機群而放在同一個初學段落。

## 每份資料說明的最低規格

每表或關係頁新增一份可折疊的資料閱讀卡，不要求每項現在就有答案：

- **業務问题與對象**：這份資料回答誰的什麼事？
- **一筆代表什麼**：目前無資料字典就填「尚未確認」，不能從表名或菱形猜主鍵。
- **時間角色**：事件發生、來源更新、擷取、快照、預測目標時間分開；未提供欄位名就只說概念。
- **關聯條件**：來源圖提供的鍵、使用者確認的業務關係、尚待驗證的 SQL 關聯分開標示。
- **多重性與去重**：已知可能多筆的原因、選最新或去重需要哪些依據。沒有穩定事件識別就不可用 DISTINCT 包治所有重複。
- **可回答／不足以回答**：例如預派回答安排，不足以證明實際加工；07:20 快照回答固定時點，不足以代表全天變化。
- **定義來源與版本**：廠內確認、假設教學例、原始圖、待確認，保留修改理由。

不能把所有表強迫塞入固定一筆粒度。尤其目前 WIP 主題含不同資料對象，應在同一主題內分別說明 KER_WIP_BT 與 KER_WIP_Y_BTH，不能讓共用一張圖暗示它們粒度相同。

## 三個必要的端到端練習

### A. 昨天這批貨走過哪些站？

題目先指定 Lot 與期間。學員選 Lot Step／Move／動作歷史，辨認 Hold 不是 Move，重工再次進同站是另一次事件；再查資料完整涵蓋期間。提供假設結果表供學員解釋，未確認真實欄位前不冒充可上線 SQL。

驗收：能說明為何不能 `COUNT(DISTINCT 站名)` 代表 Move，也不能把 FOUP 搬運次數當過站次數；遇到未涵蓋期間要回答「尚無足夠資料」，不是零。

### B. 為什麼兩個機群加起來大於全廠機台數？

假設 EQP-A 同時屬於 G1/G2、EQP-B 屬 G2。G1 一台、G2 兩台，群內台數加總三個群組成員關係；聯集只有兩台實體設備。分別展示這兩個都可能正確但回答不同問題的結果。再加入 EQP-A 的 Chamber 獨立分群，避免由腔體群直接推整台歸屬。

驗收：能說清統計對象與群組交集，不以 `COUNT(*)` 的增長推製造能力增長；不推導 AVL/EFF/LOST 彙總公式，也不先假設去重後可直接計算比率。

### C. 10:00 的模型能不能使用 10:30 才知道的結果？

用同一 Lot 的「10:00 做預估」與「10:30 量測結果可取得」簡例，對照事件時間與取得時間。這是建議新增的 DS 練習，並非宣稱目前已有相關廠內欄位。

驗收：能排除預測當時不可得的特徵；保留 PART/Flow 版本脈絡；對拆批後子批、同一 Wafer 重複紀錄的訓練／驗證切分提出洩漏檢查，而不是只以隨機列切分得到高分。無足夠識別與時間證據時標示資料集尚不可驗證。

## 與其他角色可能的取捨

新手不應先被 SQL 基數術語淹沒；可以先問「同一台出現兩次，是兩台機台嗎？」再在展開區顯示多對多術語。現場工程師需要快速找答案，因此保留直接搜尋，不強迫先修完成。導師需要判斷學會沒有，因此不可用閱讀頁數或圖片載入成功代替作答證據。完整 ER 必須保留，漸進式教學是它的導覽層，不能再用概念卡取代真實關係。
