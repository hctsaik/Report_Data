# MES 延伸教學：時間、產品路徑與配方

## 使用者要求

提供 QTime、Future Hold、Part、RouteId、LR、ER、Physical Recipe 的基本且可用於工作的說明。另提供不同 Stage／Step／Flow 說明版本，保留原版供使用者選擇。受眾僅具 Fab 基礎知識。

## 必要行為

1. QTime 明示起算與停止事件、限制單位及可追算情境；30 分鐘為示例；Hold 不自動重設本例時鐘。進站停止與出站停止可切換。
2. Future Hold 分待觸發、已觸發、此筆解除；到 S50 進站前才攔截是教學設定。解除此筆不能被呈現為解除所有加工限制。
3. Part 暫按產品／料號定義，RouteId 與版本分開顯示；不同 Lot 可共用同一產品與路徑，但目前位置不同。命名假設直接可見。
4. LR、ER、Physical 的角色分層，設備切換會更新示例對應；預期與回報版本不一致時提供加工前與加工後的不同處置說明。對應是教學模型，不冒充內部 schema，不提供真實製程參數。
5. Flow 比較頁包含原圖、層級放大、立體走站地圖、共用路徑與兩批進度對照。偏好僅本機保存，不能自動替換正式課程或推定使用者核准。
6. 各節都有情境自測、可定位解答、桌面與手機閱讀；插畫可以放大。手機主線使用原生重排，不能只把投影片縮小當作可讀。
7. 保存退回稿及修正原因、原版 hash、逐頁證據與分項評比。技術驗證不替代使用者審閱。

## 非目標

沒有連接真實 MES、沒有 Query MMDB、沒有實際 Hold 或配方下載。圖例、產品、設備與時間都是教學資料。
