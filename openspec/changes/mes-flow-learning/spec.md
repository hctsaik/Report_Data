# MES 教學第二、三部分

## 要求
1. 第二部分取代原設備課，提供可辨識的設備／搬送圖像與現場作業教學。
2. 第三部分解釋 Flow 定義、版本、Stage、Step occurrence、Lot instance、歷程、例外及追溯；主線提供一套3階段6站範例。
3. 同一流程版本可綁多Lot且各自推進。Stage完成不等於Flow完成；Recipe/Tool/Step不混用。
4. 至少16個可重玩的情境（設備6、Flow10），具有選擇、可見狀態、事件紀錄、拒絕原因及重設；錯誤操作不得偷偷推進。
5. 拆合批保持晶圓集合唯一；Hold解除不能偷做過站；返工保留前次失敗；版本發布不改在製Lot；Q-time超時不允許自行重置計時。
6. 所有流程、ID、例外批准、版本遷移與門檻皆明示教學設定，不連接真實MES。
7. 桌面與360px手机主線可讀，圖可放大、鍵盤可操作，三課互連、本機HTTP和離線可用。

## 驗收
MES-004 補充：使用者指定的 15 個 URL 為固定驗收範圍；每頁都有可獨立解讀的關係圖與新條件判斷題。兩個 lab 的主圖由實際狀態產生，不能與 Current、成員、讀值、Hold 或版本矛盾；既有 16 情境全部保留。新增概念快照切換不改動情境引擎。每頁及每張主圖分別保留桌面／手機截圖、分項評分、缺口與證據 hash。功能測試與視覺審查各自記錄。

逐情境測合法與拒絕路徑、狀態不變量、reset；逐章截桌面/手機；原圖審查與介面檢查分開記錄。舊第二課保存於workitems/mes-003/baseline，舊測試標示歷史，維護新版對應測試。
