# 全站教學架構

- 同一份catalog定義單元順序、先備、成果、現有課節/主題/任務歸屬。
- learning.html提供總覽、單元及新手/現場/資料路線；index.html原錨點保留，無錨點進總覽。
- tasks.html提供五種現場問題，以教學輸入、證據與判斷、持久進度及結論完成任務。
- topic.html與ER使用同一權威內容，具獨立深鏈、資料關係入口及來源狀態。
- 既有頁共用站點導覽/前後課及返回來源；瀏覽歷程與課程順序分開，原ER圖不改。
- 閱讀紀錄不能當作作答通過；外部深鏈沒有session仍能找到單元與首頁。
- 廠內定義與教學假設分清；未確認SQL/公式不補造；FRPORT_UDATA不回必修、Stream標示歷史。
- 驗證功能、圖片資產與代表桌手機畫面，真人學習效果待試讀。
